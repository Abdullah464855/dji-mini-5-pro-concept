# DJI Mini 5 Pro — Concept Landing Page

A concept redesign landing page for the DJI Mini 5 Pro, built as Day 1 of the "One Drone. One Landing Page. Every Day." series by Abdullahi Isola Tajudeen.

Monochrome, long-scrolling product page: hero, full specifications, camera, 225° gimbal / vertical video, safety (omnidirectional sensing + LiDAR), flight, combos, FAQ accordion, demo checkout pop-up, and footer.

## Live / Run locally

This is a single self-contained static page — `index.html` (all images inlined, no build step).

- Deploy on Vercel: import this repository, no build command, output is the repo root.
- Or open `index.html` in any browser / serve the folder with any static server.

## Notes

- The checkout is a **demo** — no payment gateway is integrated, no payment is taken, and nothing entered is sent or stored.
- Concept redesign for design demonstration. **Not affiliated with DJI.** Specs from DJI's published Mini 5 Pro materials (checked Nov 2026).
- Design/body font: Open Sans (DJI's website font stack); display headlines in DM Sans, the closest free match to DJI's proprietary DJI Sans.
